# Refund Recovery — Shopify App Store package

## App name
Refund Recovery

## One-line value proposition
Find refunds and returns that may be leaking inventory or money.

## Short description
Refund Recovery scans Shopify refund and return records for suspicious inventory states, then surfaces orders that deserve review. The app is read-only: it never issues refunds or changes inventory.

## Key benefits
- Free loss scan after install
- Dollar-at-risk summary
- Order-level evidence and reason codes
- Continuous monitoring on paid plans
- No automatic inventory or refund changes

## Pricing
- Free: on-demand loss scan
- Growth: $79/month — continuous monitoring
- Pro: $149/month — continuous monitoring for higher-volume stores

## Merchant-facing safety language
Findings are audit flags for merchant review. A flagged amount is not a promise that the amount is recoverable.
